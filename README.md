# Hole Marine

A 30-level underwater collecting game by GameDev.Land.

[Play Hole Marine](https://bolotnikov.github.io/hole-marine/) · [GameDev.Land](https://gamedev.land/ru/games/hole-marine/)

Move a growing hole across the seabed, collect fish, shells and treasure, and remove supports from physical structures. Built with TypeScript, Three.js, PixiJS, Cannon physics and GameDevLand Engine. Desktop, mobile and tablet layouts adapt to portrait and landscape orientation.

This public repository hosts the compiled web build through GitHub Pages. It contains no private source code, upload credentials, raw art sources or development diagnostics. Build provenance and file hashes are recorded in `build-info.json`.
